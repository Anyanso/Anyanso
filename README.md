## Hi there 👋

I design practical apps that solve real problems, building them quickly with AI as my development partner. I'm especially interested in **fintech** and tools that help people **invest and manage money across borders**, like investors in Canada putting money into African markets.

### 🚀 Projects

### 🛠️ How I build

- **Product first:** start from a real question, like "Is the Dangote Refinery IPO worth investing in?", and design around the people who'd use the answer.
- **AI-assisted development** with Claude: from research and design to working code.
- **Plain language:** if a feature needs a finance degree to understand, it isn't finished.
